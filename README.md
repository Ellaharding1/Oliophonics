# Oliophonic Website

This repository contains the source code for **[Oliophonic](https://oliophonic.ca/)**, a website designed to showcase a Toronto-based band with event listings, media content, and contact information.

## 📌 Live Website
**URL:** [https://oliophonic.ca/](https://oliophonic.ca/)

## 🛠️ Tech Stack
The website is built using the following technologies:

- **Frontend:**
  - HTML5, CSS3, JavaScript 
  - Responsive Design using Flexbox & Grid
  - Embedded media (images, videos, audio players)

- **Backend & Hosting:**
  - Hosted on **FastComet**
  - Static site with potential server-side enhancements (e.g., PHP for form handling)
  - Domain managed through FastComet

- **Performance & SEO:**
  - Optimized assets for fast loading times
  - Basic SEO tags for better discoverability
  - Mobile-friendly layout

- **Third-Party Integrations:**
  - Embedded **Spotify** & **Apple Music** for streaming
  - Social media links (Facebook, Instagram)
  - Contact form for inquiries
 
## 🚀 Deployment & Maintenance
- Hosted on **FastComet** for reliable uptime.
- Regular updates for events and media.
- Easily extendable with additional pages or dynamic content if needed.

## 📬 Contact
For updates, collaboration, or inquiries, visit the [Contact Page](https://oliophonic.ca/contact.html) on the website.
